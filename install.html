Install SmartBoardOS

Set it up once while online. Then teach without a connection.

Phones and tablets

iPhone and iPad

  1. Open the classroom in Safari while online.
  2. Tap Share → Add to Home Screen. If shown, switch on Open as Web App, then tap Add.
  3. Launch SmartBoardOS from its new icon while still online. Open Menu → Home and wait for Ready offline, then try reopening in Airplane Mode before class.

This installs a web app, not an App Store app or an IPA. Safari may clear site storage; export important lessons as backups. Screen recording and other device-dependent features may differ from desktop.

Android phones and tablets

The production APK link will appear after a release with the project's signing key. You can install the web app now from Chrome: open the classroom → ⋮ → Install app / Add to Home screen, then launch it online once and check Menu → Home for Ready offline.

Download the signed APK once on Android 8 or newer with an up-to-date Android System WebView. Android may ask you to allow installation from your file manager; follow your device or school policy. After installation the bundled app can open without internet, even on first launch.
